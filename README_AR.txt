مشروع فورمولا ١ - إنشاء APK تلقائيًا

يتضمن هذا المشروع لعبة HTML داخل تطبيق Android WebView، وملف GitHub Actions
لبناء APK تجريبي (Debug APK) تلقائيًا.

طريقة الحصول على APK دون Android Studio:
1) فك ضغط الملف.
2) أنشئ مستودعًا جديدًا على GitHub.
3) ارفع كل محتويات هذا المجلد إلى المستودع، مع مجلد .github.
4) افتح تبويب Actions في GitHub.
5) اختر "Build Formula 1 APK" ثم Run workflow (أو انتظر البناء بعد push إلى main).
6) بعد نجاح البناء افتح نتيجة التشغيل (workflow run) ونزّل Artifact باسم
   Formula1-debug-APK. بداخله app-debug.apk.
7) انقل APK إلى هاتف Android وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

ملاحظات:
- هذا APK تجريبي موقّع بمفتاح debug، وليس إصدار متجر Google Play.
- لا أستطيع تنفيذ عملية البناء أو رفع APK من داخل هذه الجلسة؛ GitHub Actions ينفذها.
- اللعبة تعتمد على تحميل Three.js والخط من الإنترنت، لذلك يلزم الإنترنت عند التشغيل.
- التطبيق يفتح أفقيًا وبملء الشاشة.
